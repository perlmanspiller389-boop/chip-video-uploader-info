隐私政策

适用应用：Chip Video Uploader
生效日期：2026-11-02 · 运营者：perlmanspiller389-boop

1. 适用范围

本政策说明本个人自用工具及其公开介绍网站如何处理数据。本工具使用 YouTube API Services，仅用于所有者授权的频道管理与视频上传。网站本身不接收 Google 登录凭据，也不提供访客注册或上传表单。

2. 访问和处理的数据

  • 授权信息：OAuth 客户端 ID、客户端密钥、刷新令牌，以及运行时取得的短期访问令牌。本工具不索取或保存 Google 账号密码。
  • 频道信息：通过 API 读取所授权频道的 ID、名称，以核对上传目标。
  • 上传内容：启用上传流程时处理所有者指定的视频文件、标题、说明和可见性设置；可能记录返回的视频 ID、链接和处理状态。
  • 运行记录：任务时间、执行状态、必要的频道信息和错误代码，用于排错和防止重复执行。

3. 权限与用途

youtube.readonly 用于确认已授权的频道；youtube.upload 用于执行所有者授权的视频上传。本工具仅将 Google 用户数据用于已说明的功能，不出售这些数据，不用于广告定向、信用评估或训练通用人工智能模型。

本工具对从 Google API 获取的信息的使用与转移须遵守 Google API Services User Data Policy，包括 Limited Use 要求。

4. 存储、传输与服务提供方

Google／YouTube 负责账号认证、授权和视频接收。GitHub Actions 提供云端执行，长期授权凭据保存在私有仓库的 Actions Secrets 中，并在执行时注入；短期访问令牌由程序在运行时使用。凭据不应进入公开网页、源代码或日志。

私有仓库中具有相应权限的所有者、协作者，以及所有者明确授权的管理与排障工具，可能访问任务记录。视频和元数据会按上传指令传给 YouTube。上传后的公开范围由具体视频的可见性设置决定。

Google 与 GitHub 可能为提供服务处理网络和运行数据，其处理分别适用 Google 隐私政策及 GitHub 隐私声明。

5. 保留和删除

凭据由所有者在 GitHub Secrets 中维护，直到删除、替换或撤销。云端执行临时文件随任务环境清理；运行日志及可能生成的构件按仓库的保留设置处理，也可由所有者主动删除。当前工具不提供自动执行所有数据删除的按钮。

仅在完成已授权用途所需的期限内保留 API 数据，适用时在 30 天内刷新或删除缓存数据。收到有效删除请求后，运营者应在 30 天内删除其控制范围内的相关存储数据。所有者可以在私有仓库删除授权密钥、运行日志、构件和发布记录；如曾将敏感信息写入 Git 历史，还需清理对应历史。

删除本工具的数据不会自动删除已经上传到 YouTube 的视频；这些内容需由频道所有者通过 YouTube Studio 管理。Google 和 GitHub 自身的保留规则由各自政策规定。

6. 撤销授权

可随时在 Google 账号的第三方应用访问权限页面撤销本工具的访问。撤销后，本工具不能继续依靠该授权访问频道；同时请停用相关工作流并删除 GitHub 中保存的令牌。撤销授权不等同于删除平台上的既有视频或全部历史日志。

7. 网站数据与联系

本静态网站不设置应用自有的跟踪 Cookie，不嵌入广告或分析脚本；托管服务 GitHub Pages 可能处理访问日志。

隐私问题或删除请求可通过 Google 授权界面所示的用户支持邮箱联系运营者。也可在 项目反馈页面提出不含个人资料的问题。反馈为公开内容，请勿提交密码、OAuth 密钥、令牌或其他敏感数据。

8. 政策更新

功能或数据处理方式变化时，将同步更新本政策及生效日期。新增权限应重新取得账号所有者授权。
