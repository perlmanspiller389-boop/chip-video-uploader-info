Chip Video Uploader

帮助频道所有者在云端管理芯片技术中文科普视频的上传流程。

本工具由 GitHub 用户 perlmanspiller389-boop 运营，供所有者管理自己授权的 YouTube 频道。它使用 YouTube Data API Services，目标是将所有者准备好的视频、标题和介绍上传到所选频道。

当前状态：配置与测试阶段

频道连接检查已验证。批量上传和定时发布流程仍在配置中。本页面是应用介绍页，不提供访客登录、账号注册或视频上传表单。

为什么需要授权

读取频道 ID 和名称，确认目标频道；在所有者明确指示后上传视频及相应元数据。Google 登录与授权均在 Google 官方页面完成。

谁可以使用

仅供项目所有者个人使用，不向第三方提供代运营服务。每项上传须来自所有者的指令或其已配置的发布计划。

透明的数据使用

授权凭据保存在私有上传仓库的 GitHub Actions Secrets 中。运行记录可能包含频道信息、任务状态和错误代码。详情请阅读隐私政策。

使用本工具应遵守使用条款以及 YouTube 服务条款。本工具为独立个人项目，不代表 Google 或 YouTube。

联系维护者：项目问题反馈。涉及个人资料的事项，请使用 Google 授权界面展示的支持邮箱；请勿在公开反馈中提交密钥、令牌或私人视频。
